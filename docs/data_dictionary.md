# Data dictionary

Generated by `python -m planner docs` from `src/planner/schema.py` — do not edit by hand.

## Conventions

- **Types:** `string`, `integer`, `decimal`, `boolean` (`true`/`false`; `1`/`0` in SQL), `date` (ISO `YYYY-MM-DD`), `datetime` (ISO `YYYY-MM-DDTHH:MM:SS`), `week` (ISO week label `YYYYWnn`).
- **Units:** quantities ending `_ea` are in base unit `EA`; money ending `_inr` is Indian rupees rounded to 2 dp; rates are 0–1 rounded to 4 dp.
- **Calendar:** planning weeks are ISO weeks of 2026; 2026W01 starts 2025-12-29, which is also the as-of date of the planning run.
- **Required:** `Yes` = never empty. Optional fields are empty in CSV and `NULL` in SQL.
- **Rule:** the validation rule checked by `python -m planner validate`. Rules joined with `;`.
- **Effective dating:** `effective_from` ≤ `effective_to`; an empty `effective_to` means open-ended.
